    神經網路的概念

    神經網路是一台函數學習機：用 loss 衡量答得多差，再用梯度下降一點一點修正參數。

    呆萌型 AI 機器人softmax神經元loss functiongradient descentone-hot encodingMNIST

    資料來源：課堂投影片《02 神經網路的概念》，文中（p.12）代表投影片頁碼。

    課堂重點

    深度學習最重要的是「問個好問題」：先想清楚輸入是什麼、輸出是什麼。

    先決定輸入和輸出

    AI 模型的輸入和輸出都必須是數字。例如想預測股價漲跌，可以拿過去 20 天、每天 N 個特徵當輸入，輸出兩個數字代表漲和跌。就算目標一樣，每個人選的特徵也可能不同。p.5–8

    更精確地說，輸入輸出是張量（tensor）：一個數字是 0 階、向量是 1 階、矩陣是 2 階，彩色圖片則是 3 階。p.9–10

    分類問題的答案常用 one-hot encoding 表示，例如三種八哥分別是 [1,0,0]、[0,1,0]、[0,0,1]。訓練時要準備大量有正確答案的資料，老師的估計是一個類別大約要看 1,000 張照片。p.11–13、p.24

    Softmax：把分數變成機率

    模型輸出的三個分數可能有負數，softmax 先用指數把它們都變成正數，再按比例分配，讓總和等於 1。例如分數 1.9、1.1、0.2，經過 softmax 變成 0.61、0.28、0.11。p.14–19

    \[p_i = \frac{e^{a_i}}{e^{a_1}+e^{a_2}+e^{a_3}}\]

    因為加起來是 1，常有人說模型學的是「機率分布」，也可以寫成條件機率 \(P_\theta(y_i \mid x)\)。老師提醒，這種說法「嚇人的成分居多」，電腦其實不知道第 3 類是家八哥，只知道那是第 3 類資料。p.20–25

    神經元與三大網路

    神經網路由神經元組成。每個神經元做三件事：把輸入乘上權重後加總、加上偏值（bias）、再經過激發函數。權重和偏值都是學來的參數。p.32–37

    \[h = \varphi\left(\sum_{i=1}^{3} w_i x_i + b\right)\]

    激發函數現在最常用 ReLU，Sigmoid 已經很少用。神經網路主要有三種：全連結的 DNN、擅長圖形辨識的 CNN、有記憶的 RNN，後來再加上 Transformer。p.30、p.38–39

    打造 DNN 只要決定兩件事：有幾層隱藏層、每層幾個神經元。所有權重和偏值合起來叫 \(\theta\)，\(\theta\) 一決定，函數就決定了。數學上還有萬能近似定理，保證一層隱藏層就能逼近想要的函數。p.46–52

    為什麼神經網路現在才紅

    上個世紀神經網路曾經沒落，一度連研究計畫寫「神經網路」都不會過。Yann LeCun 認為當年缺三樣東西：好用的軟體、大量資料、足夠的計算能力。現在三樣都有了。p.55–57

    Loss function：答得有多差

    還沒訓練的模型參數是隨機的，答案當然不準。我們用 loss function 計算模型答案和正確答案差多少，常見的是均方誤差：p.59–72

    \[L(\theta) = \frac{1}{2k}\sum_{i=1}^{k}\lVert y_i - f_\theta(x_i)\rVert^2\]

    例如正確答案 [1,0,0]，模型答 [0.23,0.43,0.34]，誤差平方和是 0.89。所謂「訓練」，就是想辦法讓 loss 越來越小。p.69、p.73–74

    Gradient descent：往下坡走

    先假裝只有一個參數 \(w\)：切線斜率指向上坡，所以要往相反方向走。為了不要一步跨過頭，再乘上一個小小的 learning rate \(\eta\)。p.80–92

    參數不只一個時，就「假裝只有一個」，對每個參數各自做偏微分。所有偏微分組成的向量叫梯度 \(\nabla L\)，更新公式是 \(\theta \leftarrow \theta - \eta \nabla L\)。不管網路怎麼架、loss 怎麼選，都能用這個方法訓練。p.93–104

    實作：MNIST 手寫辨識

    用 TensorFlow 打造第一個神經網路。MNIST 的圖片是 28×28，拉平成 784 維輸入，輸出 10 維代表 0～9。範例用兩層各 100 個神經元的隱藏層、ReLU 激發函數，輸出層用 softmax，訓練方法是 SGD。p.109–122

    重要名詞

    • 張量（tensor）：輸入輸出的資料形式，可以是數字、向量、矩陣或更高維的陣列。
    • one-hot encoding：用只有一個 1、其他都是 0 的向量表示類別。
    • softmax：把任意分數轉成「大小關係不變、總和為 1」的一組數字。
    • 神經元：神經網路的基本運算單元，做加權總和、加偏值、過激發函數。
    • ReLU：目前最常用的激發函數，負數變 0，正數照舊。
    • loss function：衡量模型答案和正確答案差距的函數，越小越好。
    • gradient descent：沿著梯度的反方向調整參數，讓 loss 變小的訓練方法。
    • learning rate：每次調整參數的步伐大小，太大會跑過頭。
