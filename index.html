    TAICA 生成式 AI 課程

    生成式 AI 課程筆記

    這裡是我修「生成式 AI：文字與圖像生成的原理與實務」的每週筆記。每篇都從課堂投影片整理而來，標了投影片頁碼，方便回去對照。

    整學期的主線只有一句話：

    AI Agent 其實只是「教 AI 做事的方法」。

    課程用一條路線串起所有名詞：Chat Bot → Prompt Engineering → Context Engineering → Harness Engineering → Loop Engineering → Graph Engineering → AI Agent。前半學期先把原理打底（神經網路、GAN、LLM、Transformer），後半學期開始動手做對話機器人、RAG 和 AI Agent。

    怎麼使用這個網站

    • 左邊目錄依週次排列，每篇的格式都一樣：課堂重點、重要名詞、本週作業、和其他週的關係、延伸思考。
    • 文中的橘色小字（例如 p.12）是投影片頁碼。
    • 左上的搜尋框可以找標題、關鍵字和內文，按 / 可以直接開始輸入。
    • 關鍵字索引 把同一個概念出現在哪幾週整理在一起。

    每週筆記

    • W01如何不焦慮地學 AI懂原理就不焦慮：AI 只是呆萌型機器人，AI Agent 就是教 AI 用我們的方法做事。
    • W02神經網路的概念神經網路是一台函數學習機：用 loss 衡量答得多差，再用梯度下降一點一點修正參數。
    • W03AI 為什麼每次都不一樣？創作型 AI 靠隨機性產生不同結果：GAN 從隨機 latent 出發，語言模型則是依機率抽字。
    • W04LLM 只是在猜下一個字？文字生成 AI 就是一直預測下一個字，選字方式決定它有多隨機，prompt 要給正確資訊和清楚指引。
    • W05AI 怎麼記得前面說過什麼？拆解 RNN 和 Transformer 的記憶方式：QKV 注意力、位置編碼和讓網路更穩的設計。
    • W06打造自己的對話機器人用 system prompt 給 LLM 人設，再用 AISuite 寫程式，打造自己的對話機器人。
    • W07讓 AI 看懂你的世界RAG 先找出相關資料再交給 LLM 回答；LLM Wiki 則讓 AI 自己整理知識庫。
    • W08教 AI 做事的方法AI Agent 就是教 AI 用我們做事的方法，吳恩達整理出四種設計模式。
    • W09換你當老闆從「問 AI」變成「交辦給 AI」：靠 harness 和員工手冊，讓 AI Agent 真的動手把工作做完。
